
1. What is the Bootstrap grid system?
The Bootstrap grid system is a layout system that uses a series of containers, rows, and columns to design responsive web layouts that adapt to different screen sizes.
It is based on a 12-column grid, allowing developers to define how much width each element should take across various device sizes (e.g., col-sm-6, col-md-4).
✅ Example:
<div class="container">
  <div class="row">
    <div class="col-md-6">Column 1</div>
    <div class="col-md-6">Column 2</div>
  </div>
</div>

This creates two equal columns that adjust automatically on smaller screens.

2. Why use semantic tags (<header>, <footer>, <nav>) instead of <div> tags?
Semantic tags describe the purpose and meaning of content to both browsers and developers.
They improve accessibility, SEO (search engine optimization), and make code more readable.
Using <div> for everything does not convey meaning about the structure of the page.
✅ Example:
<header>Website Header</header>
<nav>Navigation Links</nav>
<footer>Footer Content</footer>


3. What is an "event listener" in JavaScript?
An event listener waits for a specific event (like a click) to occur on an element, then executes a function.
✅ Example:
document.getElementById('submit-btn')
  .addEventListener('click', validateForm);

This code listens for a click on the button with ID submit-btn and runs validateForm().

4. Why does “undefined” appear on a webpage?
“undefined” usually appears when:


You try to display a variable that has not been assigned a value, or


You return nothing from a function and then try to display its value.


✅ Example:
let name;
console.log(name); // undefined


5. How does fetch() work for GET and POST requests?
✅ GET request:
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data));

✅ POST request:
fetch('https://api.example.com/submit', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({name: 'John', age: 25})
})
.then(response => response.json())
.then(data => console.log(data));

7. What is a void (empty) tag in HTML?
A void tag does not have a closing tag and cannot contain content.
✅ Examples:


<img src="image.jpg" alt="image">


<br> (line break)

9. CSS Positioning Scenario
If the outer <div> has no positioning set, the inner <span> (with position: absolute; top:0; left:0;) will be positioned relative to the page (viewport).
✅ To make it position relative to the outer <div>, add:
.outer-div {
  position: relative;
}


10. innerHTML vs textContent


innerHTML → Inserts HTML code inside an element.


textContent → Inserts plain text (HTML tags are not rendered).


✅ Example:
element.innerHTML = "<b>Hello</b>"; // Bold text
element.textContent = "<b>Hello</b>"; // Shows <b>Hello</b>

👉 Use textContent when only inserting text (for safety and speed).

12. Lifecycle of a Page


Parsing HTML → Browser reads HTML and builds DOM.


Load CSS/JS → Stylesheets and scripts are loaded.


DOMContentLoaded → DOM fully built (but not necessarily images).


Load Event → Page fully loaded (including images).


User Interaction → Events handled dynamically.


Unload/BeforeUnload → When user leaves or closes the page.
